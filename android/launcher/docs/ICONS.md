# Значки портов: требования и генерация

Основано на значках homm5, stronghold_crusader и the_void (единственные порты со своими значками;
ut3, bioshock, crashday, majesty_gold_hd, frostpunk и the_sims_2 значков не имеют — у них системный
значок по умолчанию). Ни в одном проекте нет исходников (SVG/PSD) и инструментов генерации: пути
нарисованы вручную прямо в VectorDrawable XML.

## 2. Требования (нормативные)

### 2.1 Формат
- **Adaptive icon**, `res/mipmap-anydpi-v26/ic_<id>.xml` (background + foreground) и
  `res/mipmap-anydpi-v33/ic_<id>.xml` (те же + monochrome). При `minSdk 26` растровые `mipmap-*dpi`
  не нужны. `<monochrome>` держать в `-v33` (у the_void он лежит в v26 — работает, но нестандартно).
- В манифесте `android:icon` и `android:roundIcon` указывают на один и тот же adaptive mipmap.
- Слои — только **VectorDrawable**: `path`, `group` (трансформации), `clip-path`, сплошные заливки,
  градиенты через `aapt:attr`. Без растров, без текста как текста (буквы — только контурами), без
  обводок тоньше 1,5 dp.
- Холст **108×108 dp**, `viewportWidth/Height = 108` (1 единица = 1 dp, центр — (54,54)).

### 2.2 Геометрия
- **Safe zone:** вся значимая графика переднего плана — внутри круга ⌀66 dp (радиус 33 от центра).
  Это единственная область, которую не обрежет ни одна маска (круг, squircle, капля, скруглённый квадрат).
- 66–72 dp (радиус 33–36): маска может срезать — только второстепенное (свечение, края ореола).
- Дальше 72 dp (радиус 36): не видно никогда, это поле для параллакса/анимации лаунчера.
- Оптический размер: основной силуэт 48–60 dp по большей стороне; тяжёлые формы (щит) — ближе к 52.

### 2.3 Слои
- **Background** — непрозрачный на всей площади 108×108 (иначе на некоторых лаунчерах просвечивает
  чёрное). Сплошной цвет (`@color/ic_<id>_background`) или вектор с градиентом без мелких деталей.
- **Foreground** — прозрачный вокруг силуэта; контраст основного силуэта с фоном ≥ 3:1.
- **Monochrome** (Android 13+, тематические значки) — система берёт только альфу и красит в цвет
  темы. Тот же силуэт, что у переднего плана; внутренние детали, которые в цветном варианте
  нарисованы «цветом фона», здесь вырезаются (`fillType="evenOdd"`), как у Crusader. Нельзя
  переиспользовать передний план, если смысл держится на цвете (у Extreme мечи «за» щитом в цвете,
  а в monochrome пересекают вырез замка — проверить глазами).
- **Notification** — `drawable/ic_notify.xml`, 24×24 dp, белый силуэт без цвета (из monochrome,
  вписанный в 20 dp). Сейчас все порты показывают в уведомлениях системные `stat_sys_download`.

### 2.4 Дистрибутивы
- У каждого дистрибутива свой adaptive-значок `ic_<distribution>`: для карточек в лаунчере, для
  задачи игры в «Недавних» (`android:icon` у Activity дистрибутива, как в stronghold) и для
  ярлыков (long-press на значке приложения).
- Различать **формой, а не только цветом** (дальтонизм, monochrome-режим): общий «герб» серии +
  отличительная эмблема дистрибутива (мечи у Extreme — правильно; Stronghold HD сейчас отличается
  только фоном — нужна своя эмблема).
- Значок приложения = значок дистрибутива по умолчанию или общий значок серии.

### 2.5 Авторские права
- Не использовать логотипы, обложки и арт оригинальных игр (`pub/*_icon.jpg`, `.ico` из игры): APK
  публикуется. Нынешние значки — собственные абстракции (щит, капля, герб) — это правильный путь.

### 2.6 Android TV (если порт будет запускаться на ТВ-боксах)
- `android:banner` 320×180 px в `drawable-xhdpi` (160×90 dp) и категория `LEANBACK_LAUNCHER`.
  Готовый пример размера есть в `the_closing_shift/app/res/drawable-xhdpi/app_banner.png`.

## 3. Исправления существующих значков

Минимальные правки без перерисовки — обернуть передний план (и monochrome) в масштабирующую группу:

```xml
<group android:pivotX="54" android:pivotY="54" android:scaleX="0.95" android:scaleY="0.95">
    <!-- existing paths -->
</group>
```

- homm5: `scale 0.95` → 32,27 dp.
- stronghold Extreme: `scale 0.92` → 32,55 dp (или укоротить клинки до y=31).
- Stronghold HD: своя эмблема; вырез замка — `evenOdd` вместо заливки `#162A35`.
- the_void: перенести `<monochrome>` в `mipmap-anydpi-v33/ic_launcher.xml`, добавить `roundIcon`.

## 4. Проверка и генерация (`tools/icons.py`)

`check` уже есть (слои v26/v33, monochrome, растры, фон на весь холст, safe zone с учётом трансформаций
`<group>`). Генерация из `icons.json` (`init`/`build`) — следующий шаг; ниже — её задуманный вид.

**Источник** — `android/icon/icons.json` порта (или SVG из Inkscape в режиме «Plain SVG»:
`path`/`rect`/`circle`/`polygon`/`g transform` переводятся в `pathData`):

```json
{
  "icons": {
    "toe": {
      "background": {"color": "#142230"},
      "foreground": [{"fill": "#EBCB7F", "fillType": "evenOdd", "path": "M54,23 L79,31 ..."}],
      "monochrome": "auto",
      "scale": 0.95
    }
  },
  "app": "toe",
  "notification": "toe"
}
```

**Выход** (детерминированный, перезаписывается целиком):
- `res/drawable/ic_<id>_foreground.xml`, `ic_<id>_monochrome.xml`, `ic_<id>_background.xml` (если не цвет),
  `ic_notify.xml`;
- `res/mipmap-anydpi-v26/ic_<id>.xml`, `res/mipmap-anydpi-v33/ic_<id>.xml`;
- `res/values/ic_colors.xml`;
- `build/icons/preview.png` — сетка: каждый значок под масками «круг / squircle / скруглённый
  квадрат / капля», monochrome на светлой и тёмной теме, уведомление 24 dp; плюс `512×512` PNG для
  README/релиза.

**`monochrome: "auto"`** — объединение путей переднего плана, у которых непрозрачность ≥ 50%;
пути, совпадающие по цвету с фоном, превращаются в вырезы (evenOdd). Результат всё равно
просматривается на превью.

**Проверки `icons.py check`** (ошибка — сборка APK останавливается):
- геометрия переднего плана и monochrome в круге r ≤ 33 (предупреждение до 36, ошибка дальше);
- фон непрозрачен на всём холсте; передний план не залит целиком;
- у каждого дистрибутива есть значок; в v33 есть monochrome; имена уникальны;
- нет растров и `<text>`; только поддерживаемые VectorDrawable элементы;
- контраст силуэта с фоном ≥ 3:1;
- `--device`: рендер через `AdaptiveIconDrawable` на устройстве (как `LauncherIconSelfcheck` в stronghold).

**Значок по умолчанию** для портов без значка (ut3, frostpunk и др.): `icons.py init` создаёт
`icons.json` из темы порта (`theme.accent` / фон) с нейтральным гербом-заготовкой и монограммой из
контуров — чтобы новый порт с первого дня имел корректный adaptive-значок.
